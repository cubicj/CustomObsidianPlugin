# CubicJ Core

Personal all-in-one quality-of-life plugin for [Obsidian](https://obsidian.md). Built for my own vault, so defaults are opinionated and there are no compatibility promises.

## Features

- **Font loader** — loads custom fonts from a vault folder and injects them as `@font-face` styles.
- **No auto focus** — stops the editor from grabbing focus when a note opens.
- **Frontmatter dates** — keeps created/updated date properties in frontmatter up to date automatically.
- **Note format** — normalizes markdown notes on local edits, with a manual bulk-format button in settings.
- **Fold properties** — collapses the frontmatter Properties block by default.
- **Reading folds** — applies saved fold state before Reading View first paints.
- **Fold remap** — keeps heading folds stable when notes change under external edits.
- **Sticky view mode** — remembers editing/reading mode per tab.
- **Eager parse** — parses the visible viewport eagerly in editing mode to remove styling lag.
- **Reading brackets** — styles `[bracketed]` text as highlighted markers in Reading View.
- **Reading list blank lines** — restores blank-line spacing between list items in Reading View.
- **Vault replace** — vault-wide find and replace with match preview.
- **No alt multi-cursor** — disables alt-click multi-cursor while keeping rectangular selection.
- **Sidebar commands** — direction-specific sidebar collapse and expand commands for hotkeys.
